title: "Query with PromQL in CloudWatch"
sidebar_position: 30
---

Amazon CloudWatch Query Studio is a unified query interface that lets you explore metrics using both PromQL (Prometheus Query Language) and SQL syntax. It provides auto-completion, a metric browser, and a visual query builder so you can explore OpenTelemetry-ingested metrics, enriched AWS vended metrics, and custom application metrics from a single pane.
