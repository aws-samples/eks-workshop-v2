## Key Findings

### From eks-troubleshooting-workshop (GitLab)

**Authentication Pattern:**
- Uses a CloudFormation stack (`kiro-identity-center-stack.json`) that:
  - Creates an AWS SSO Instance
  - Creates a Lambda that provisions an IDC user (`kiro`), generates OTP password, disables MFA
  - Creates a Kiro/Q Developer Pro+ profile and assigns the user
  - Outputs: `KiroStartURL`, `KiroUser`, `KiroPassword`, `KiroRegion`
- Participants authenticate via `kiro-cli login --use-device-flow` → "Use with Your Organization"

**MCP Configuration (AWS-Hosted):**
```json
{
  "mcpServers": {
    "eks-mcp": {
      "command": "uvx",
      "args": [
        "mcp-proxy-for-aws@latest",
        "https://eks-mcp.<region>.api.aws/mcp",
        "--service", "eks-mcp",
        "--region", "<region>"
      ]
    }
  }
}
```

**IAM Permissions Required for Hosted MCP:**
```json
{
  "Action": [
    "eks-mcp:InvokeMcp",
    "eks-mcp:CallReadOnlyTool",
    "eks-mcp:CallPrivilegedTool"
  ],
  "Resource": ["*"]
}
```

**Kiro CLI Install:**
```bash
curl -fsSL https://cli.kiro.dev/install | bash
```

**Steering/Config paths:**
- MCP config: `~/.kiro/settings/mcp.json`
- Steering rules: `.kiro/steering/*.md`

## Decisions Made

1. **Authentication method for workshop events:** Option B — IDC in base Terraform (`manifests/.workshop/terraform/base.tf`)
   - Deploy a `kiro-identity-center-stack.json` CloudFormation template during cluster setup (pre-provisioned, no user wait)
   - Provisions:
     - AWS IAM Identity Center (SSO) instance
     - Lambda that creates IDC user `kiro`, generates OTP password, disables MFA
     - Q Developer Pro+ profile with user assignment
     - Outputs: `KiroStartURL`, `KiroUser`, `KiroPassword`, `KiroRegion`
   - Participants use `kiro-cli login --use-device-flow` → "Use with Your Organization"
   - Workshop content includes step-by-step instructions on retrieving IDC credentials from CloudFormation outputs
   - Self-paced users can still use "Use with Builder ID" as fallback

2. **Force-push rebase?** — Yes, required to get branch current with main

3. **Kiro CLI version:** Latest installer (`curl -fsSL https://cli.kiro.dev/install | bash`)

4. **MCP config:** Generated via Terraform `templatefile()` (Option C) — no hardcoded region

5. **Additional MCP servers:** Include `aws-mcp` alongside `eks-mcp`
